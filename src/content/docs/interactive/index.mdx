---
title: Interactive Lab｜互動實驗室
---

這裡把公式轉成可以操作與觀察的 toy systems。這些 visualization 用來建立 physical / mathematical intuition，**不是 experimental evidence**。

- **Probability Path Explorer** — 拖動時間 $t$，觀察 $z_t$ 如何從 data interpolation 到 prior。
- **Conditional vs Marginal Velocity** — 重新抽樣 pair，觀察為什麼 $e-x$ 不是唯一的 field value。
- **JVP Explorer** — 改變 interval 長度，理解 average velocity 與 local velocity 的關係。
- **MF vs iMF Objective Explorer** — 在 Original MF、equivalent v-loss 與 iMF 之間切換。

相同的 interactive components 也會嵌在對應的 handbook equation 附近，讓 visualization 出現在最需要它的概念位置。
