# Research Knowledge Graph

這張圖不是單向的 paper timeline，也不是每個節點只能有一個 parent 的樹。**Diffusion → Flow Matching → MeanFlow** 只負責提供主線；MeanFlow 之後的問題會向外發散，同一篇 paper、concept 或過去方法也可以和多個問題產生關聯。

<ResearchKnowledgeGraph lang="zh" />

## 怎麼讀

- **主線**：理解方法怎麼一路走到 MeanFlow。
- **Research branch**：representation / NFE、training dynamics、objective / JVP、endpoint / refinement、distribution correctness。
- **Paper node**：已有直接理論或實驗 evidence 的工作，可點進獨立筆記。
- **Concept / transfer node**：可能從過去方法移植的 design lens；虛線表示「可借鏡，不代表已證明有效」。

## 目前最值得追的交叉問題

$r=t$ 時有 $u(z_t,t,t)=v(z_t,t)$，因此 boundary learning 與 instantaneous velocity 直接相連；另一方面 AlphaFlow 與 MeanFlow training-dynamics work 都指出 optimization / temporal-gap ordering 的重要性。這讓「先 local / small-gap，再 large-gap」不只是一條 training branch，也和 representation、objective stability 有交叉連結。
