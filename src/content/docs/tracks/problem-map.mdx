# Research Problem Map

這張圖的單位不是「章節」或「paper」，而是 **research question**。每個問題都可能由多篇論文部分回答，也可能產生新的可驗證 hypothesis。

<ResearchProblemMap lang="zh" />

## 如何讀這張圖

- **Foundation**：目前問題依賴的基礎 framework。
- **Research Question**：從閱讀、推導、實驗或實作中浮現的具體疑問。
- **Paper / Evidence**：對該問題提供理論、ablation、controlled experiment 或 empirical result 的 paper。
- **Open hypothesis**：目前證據只支持較一般的方向，但更具體的版本仍值得自己做實驗。

## Q2 的證據層級示例：$r=t$ 是否應該先學？

### Hypothesis

$r=t$ 時 $u(z,t,t)=v(z,t)$，因此先建立 boundary / instantaneous ability，再學 large temporal gap，可能比一開始混合所有 interval 更穩。

### Paper-supported evidence

**AlphaFlow**：指出原始 MeanFlow 大量使用 $r=t$ boundary supervision；其分析把 MeanFlow 拆成 trajectory flow matching 與 trajectory consistency，發現兩者存在強 gradient conflict，並用從 trajectory flow matching 漸進到 MeanFlow 的 curriculum 改善 convergence。

**Understanding, Accelerating, and Improving MeanFlow Training**：controlled experiments 顯示 instantaneous velocity 要先形成；small-gap average velocity 會幫助 $v$，large-gap supervision 太早加入會破壞 $v$；因此提出 short-to-long temporal-gap curriculum。

### 尚未被完全回答

「先做固定 epochs 的 pure $r=t$ pretraining，再打開其他 interval」是比上述 papers 更具體的 protocol。現有證據讓它成為合理 hypothesis，但仍需要直接 ablation：

| Protocol | Stage 1 | Stage 2 | 要回答的問題 |
|---|---|---|---|
| Baseline | 全 gap 混合 | 全 gap 混合 | 原始參考 |
| Boundary warm-up | 只取 $r=t$ | 全 gap | pure boundary 是否最穩？ |
| Small-gap warm-up | $\Delta t\le\delta$ | 全 gap | 是否比 pure boundary 更有 transfer？ |
| Progressive gap | small → medium | → large | curriculum 是否需要平滑 transition？ |

這種「**Hypothesis → Existing Evidence → Missing Ablation**」會成為本站之後整理研究問題的固定格式。
