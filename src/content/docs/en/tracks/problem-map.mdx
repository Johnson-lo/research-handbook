# Research Problem Tree

This map is organized by **parent-child research questions**, not publication year: first trace the mainstream path into MeanFlow, then inspect the questions MeanFlow has not fully closed.

<ResearchTreeMap lang="en" />

## How to use the tree

- Trunk: **Diffusion / Score-based → Flow Matching → MeanFlow**.
- Question nodes: active issues in representation, training dynamics, JVP objective design, endpoint quality, and distribution correctness.
- Paper children: papers that provide direct evidence for that question.
- Transfer lenses: design ideas from earlier methods that are plausible to test but are not yet established MeanFlow solutions.

## Example: should $r=t$ / small-$\Delta t$ be learned first?

At $r=t$,

$$
u(z_t,t,t)=v(z_t,t),
$$

so boundary learning is the limiting instantaneous-velocity case. AlphaFlow's gradient-conflict analysis and the CVPR 2026 MeanFlow training-dynamics experiments both support forming more local capabilities before large-gap MeanFlow learning. Whether a strict $r=t$-only warm-up is the best protocol remains an open ablation.
