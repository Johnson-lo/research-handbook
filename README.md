# Johnson's Research Handbook

Public research handbook for Flow Matching, MeanFlow, fast generative modeling, and robotics.

## Stack

- Astro 7
- Starlight
- Markdown / MDX
- Vanilla Astro components for interactive demos
- GitHub Pages deployment through GitHub Actions

## Development

```bash
npm install
npm run dev
```

## Deployment target

Repository: `Johnson-lo/research-handbook`
Deployment URL: `https://johnson-lo.github.io/research-handbook/`

If the repository name changes, update `base` in `astro.config.mjs`.
